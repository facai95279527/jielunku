# 5～10 分钟快速清单（按顺序做）

在「你的 Clash 类 App」名称上操作（Clash Meta / FlClash / CMFA 等，下文统称 Clash）：

  1. 省电策略 → 无限制
    设置 → 应用设置 → 应用管理 → Clash → 省电策略（或电池）→ 无限制（不要「智能推荐 / 限制」）。

  2. 自启动 + 关联启动
    设置 → 应用设置 → 权限管理 → 自启动管理 → 允许 Clash。
    同一应用详情里如有「关联启动」「后台弹出界面」，一并允许。

  3. 最近任务锁定
    多任务界面 → 长按 Clash 卡片 → 点 锁形图标（锁定），勿从多任务强行划掉。

  4. 关掉会冻死后台的省电
    关闭「超级省电 / 极限省电」；在「应用智能管控 / 休眠 / 神隐模式」里把 Clash 移出受限制列表。

  5. 专用 DNS（Private DNS）先关掉
    设置 → 更多连接（或网络与互联网）→ 专用 DNS / 私人 DNS → 选 关闭 或 自动。
    若填了 dns.adguard.com 等主机名，容易出现「钥匙亮着但全网打不开」。

  6. 始终开启的 VPN
    设置 → 网络与互联网 / VPN → 若开启了「始终开启的 VPN」且指向别的 App，先关掉或改成当前 Clash；Android 同一时间只能有一个活动 VPN。

  7. 重新授权 VPN
    打开 Clash → 开启 TUN/VPN → 系统弹窗点允许。状态栏应出现 钥匙图标，且通知栏常驻通知不要关（关掉有时等于掐断前台服务）。

  8. 更新订阅并测节点
    订阅 → 更新；对节点做延迟测试；选一条延迟正常的。全挂则是节点/订阅问题，不是小米省电。

  9. Wi‑Fi 与蜂窝各测一次
    息屏 5～15 分钟后再亮屏看钥匙是否还在、网页是否还能开。

做完 1～7，多数「锁屏断代理」会明显好转。

# 常见原因与具体修复（由常见到少见）
## 1. 电池优化 / 省电策略 / 后台锁定（最常见）

小米对后台 VPN 服务很激进：锁屏后回收进程 → 通知消失 → 流量变直连或超时。

修复：

  • 应用管理 → Clash → 省电策略 = 无限制
  • 电池与性能 / 应用智能管控 → 关闭对该应用的「内存与后台占用」限制（路径因 MIUI/HyperOS 版本略有不同，设置内搜「省电」「后台」「Clash」）
  • 最近任务 锁定 Clash
  • 允许通知（前台服务依赖常驻通知）

系统原生「忽略电池优化」与小米自己的「省电策略」是两套，两处都要放行。

## 2. 始终开启的 VPN 冲突

系统「始终开启的 VPN」若绑定了旧 App（WARP、公司 VPN、旧 Clash），新客户端无法建立隧道，或反复抢占。

修复： VPN 列表里关掉其他连接与「始终开启」；只保留当前要用的客户端后再开。

## 3. 专用 DNS / 私人 DNS 破坏 TUN

系统 Private DNS 走主机名解析；与 Clash TUN / fake-ip 叠在一起时，常见表现是：测速正常、钥匙带感叹号、网页全挂。

修复： 专用 DNS → 关闭或自动；DNS 交给 Clash 配置（见下文 fake-ip）。排除后再按需加回。

## 4. 智能省电、神隐模式、应用休眠

超级省电、休眠名单、神隐会冻死非白名单应用。

修复： 退出超级省电；从休眠/神隐名单移除 Clash；勿把 Clash 设为「限制后台」。

## 5. 应用分身 / 双开 / 工作资料（Work Profile）

分身里的 Clash 与主用户权限、VPN 授权相互独立；工作资料隔离会导致「主系统有网、分身没网」或权限弹窗找不到。

修复： 在实际使用的用户空间安装并授权；尽量不要在分身里跑 VPN，或主/分身只保留一份。

## 6. 关联启动、显示悬浮窗、后台弹出界面

小米可能拦截 Clash 拉起自己或弹出 VPN 授权窗。

修复： 应用详情 → 权限 → 允许 自启动、关联启动、后台弹出界面；需要时允许悬浮窗。

## 8. 模式设错：Rule / Global / Direct；fake-ip / redir-host；TUN / 系统代理
  • Direct：全部直连，看起来「开了等于没开」
  • Global：全部走代理，国内 App 可能变慢或异常
  • Rule（推荐日常）：按规则分流

DNS：

  • Android + TUN 下多数情况 fake-ip 更省电、更稳
  • redir-host 在部分环境下更「直观」，但耗电与兼容性因机而异

接入方式：

  • TUN（系统 VPN）：接管 TCP/UDP，游戏/部分 App 需要；小米上就是状态栏钥匙
  • 仅系统代理：只管 HTTP(S)，不少 App 绕过

建议： 日常用 Rule + TUN + fake-ip；国内银行/支付可在「分应用代理」里设为绕过（bypass）。

## 9. 订阅过期 / 节点全死 / TLS 指纹问题

表现：延迟全超时或连接瞬间失败；与省电无关。

修复： 更新订阅；换节点/换线路；核对订阅 URL 未过期；看客户端日志里 TLS/握手错误。仍大面积失败则联系订阅服务商，或换客户端试同一订阅（排除客户端 bug）。

## 10. IPv6 / Wi‑Fi 助手 / 智能选网

运营商 IPv6 与代理 DNS 冲突时，常见「4G/5G 不行、Wi‑Fi 正常」。

修复：

  • Clash 网络设置里 关闭 IPv6（若有开关）
  • 系统关闭「Wi‑Fi 助手 / 智能选网 / 双 Wi‑Fi」试一次
  • Wi‑Fi 高级设置里保持锁屏后 Wi‑Fi 连接（若存在该选项）
## 11. HyperOS 更新后 VPN 权限被收回

大版本更新后 VpnService 授权可能重置。

修复： 打开 Clash 重新点连接 → 允许 VPN；必要时应用信息 → 清除「限制」后重授；再走一遍省电无限制。

# 进阶排查（快速清单无效时）
  1. 看日志：Clash → 日志 / Log，区分「进程被杀」「DNS 失败」「节点握手失败」。
  2. 安全模式对比：临时关专用 DNS、关 IPv6、模式改 Global 测一条已知可用节点；能通再改回 Rule。
  3. 分应用：确认浏览器没被误加「拒绝代理」；系统应用（短信、电话、应用商店）建议绕过 VPN，减少异常。
  4. 换客户端验证：同一订阅在 FlClash 与 CMFA 各试一次——两边都挂 → 订阅/网络；只有一边挂 → 客户端或权限。
  5. 勿叠加多个 VPN：Clash + WARP + 公司 VPN 同时开会互相抢隧道。

  • 仓库：https://github.com/chen08209/FlClash

## 2. Clash Meta for Android（CMFA）
  • 适合谁：习惯经典 Clash 安卓界面、要 Meta/mihomo 能力。
  • 小米注意：同上，保活靠系统白名单；社区文档最多。
  • 下载：
  • GitHub：https://github.com/MetaCubeX/ClashMetaForAndroid/releases
  • F-Droid：https://f-droid.org/packages/com.github.metacubex.clash.meta/
  • 最少配置：Profiles 添加订阅 → Update → Mode=Rule → 开 TUN → 分应用里给微信/银行等设 bypass（按需）。
## 3. sing-box for Android（SFA）
  • 适合谁：订阅/配置是 sing-box 格式，或想用官方 SFA。
  • 小米注意：同样 VpnService；配置门槛略高于 FlClash。
  • 下载：https://github.com/SagerNet/sing-box/releases（资源名形如 SFA-*-arm64-v8a.apk）
  • 最少配置：导入配置或订阅 → 启动 → 授 VPN；小米保活步骤同第一部分。
## 4. v2rayNG
  • 适合谁：VMess / VLESS / Trojan 等 Xray 系分享链接或订阅。
  • 小米注意：专用 DNS 冲突表现与 Clash 相同；Play 外只信官方 GitHub。
  • 下载：https://github.com/2dust/v2rayNG/releases
  • 最少配置：+ → 订阅设置 → 更新 → 选节点连接；需要全局 UDP 时开 TUN（若版本提供）；关专用 DNS 再测。
## 5. Hiddify
  • 适合谁：想要「一键导入多种订阅」（Sing-box / Clash / V2ray 等）、界面偏小白。
  • 说明：不提供服务器，需自备节点；有 Google Play 与 GitHub。
  • 下载：
  • GitHub：https://github.com/hiddify/hiddify-app/releases
  • Play：https://play.google.com/store/apps/details?id=app.hiddify.com
  • 最少配置：粘贴订阅 → 连接 → 小米保活同前。
## 6. Surfboard（可选）
  • 适合谁：已有 Surge 兼容 配置的用户。
  • 下载：https://github.com/getsurfboard/surfboard/releases（如 mobile-arm64-v8a-release.apk）
  • 最少配置：导入配置 → 启动 VPN → 同样做小米后台白名单。
## 参考：NekoBox for Android
  • 通用 sing-box 工具链，偏进阶；维护频率较低，作者亦建议机场用户优先 CMFA/FlClash。
  • 下载：https://github.com/MatsuriDayo/NekoBoxForAndroid/releases
  • 不要从 Google Play 装宣称同名的冒充包（项目 README 有警告）。
# B. 商业 / 正规 VPN（自带服务器）

适合「不想维护订阅、只要加密出口」的场景；能否在你所在网络稳定使用，需你自己试用。小米上同样建议关闭电池限制。

## Mullvad VPN（付费、注重匿名）
  • 按账号时长付费，可用现金等；无日志立场明确。
  • 下载：https://mullvad.net/en/download/vpn/android（官网 APK / GitHub；亦有 Play、F-Droid 说明）
  • 官方亦提到 Xiaomi 等机型锁屏易断，需关电池优化。
## Proton VPN（有免费档 + 付费）
  • 瑞士公司；免费档有服务器与速度限制，付费功能更多。
  • 下载：https://protonvpn.com/download-android（Play / F-Droid / GitHub APK）
## IVPN（付费、开源客户端）
  • 开源 Android 客户端；文档称 Play 可能暂时下架，用官网 APK 或 Accrescent。
  • 下载页：https://www.ivpn.net/en/apps-android/
## Cloudflare 1.1.1.1 + WARP（免费档常见）
  • 偏「加密到 Cloudflare、改善隐私/部分网络」，不是传统「选国别出口」的机场替代；与 Clash 不要同时开。
  • 官网：https://one.one.one.one/
  • Play：https://play.google.com/store/apps/details?id=com.cloudflare.onedotonedotonedotone

「保活难度高」= 小米省电策略不放行就会断，与选哪款代理核心关系不大。

若你确认就是小米 + Clash：建议路径
  1. 先花 10 分钟做完 快速清单（省电无限制、自启、锁定、关专用 DNS、重授 VPN）。
  2. 仍不稳 → 同一订阅改装 FlClash 或 CMFA 对比。
  3. 不想管订阅 → 试 Proton（可先免费） 或 Mullvad；只要加密出口可试 WARP（与 Clash 二选一）。
  4. 银行/支付异常 → 分应用里对该 App 绕过 VPN。
免责声明（再强调）
  • 本文仅为技术排查与公开客户端信息整理。
  • 请自行确认使用 VPN/代理是否符合你所在地法律、雇主或校园网络规定。
  • 勿安装来路不明的 APK；勿把订阅链接发给不可信方。
