4. 2026-10-15 司法拍卖信息差赚钱方向调研（已交付）

聊天原文

之前一直挂着待办的司法拍卖信息差调研，现在整理好了。

从门槛低到高大致是这几种做法：
- 整理本地法拍信息，做社群引流。
- 代拍或辅拍。北京一般收成交价的 1% 到 2%，但监管在收紧，帮人清场这类服务也越来越不值钱。
- 捡漏自住或者转售。算上所有成本后要低于市价约六折才有空间，公司产权的房子税费坑很大。
- 不良资产包，门槛最高。

住宅以外，相对能碰的是法拍车、罚没品和破产企业打包卖的商标。法拍车的公告常常不写违章和车况，要自己查。股权、厂房、商铺门槛都高，而且多数品类找不到可靠的收益数据。

南宁这边，2025 年以来网拍住宅成交率约 62%，青秀区均价约每平米 7503 元。望园路青年国际适合盯二拍和变卖。算账时用成交价加上税费、欠费，再加约 10% 的其他成本，跟同小区的二手价比。

司法拍卖“信息差”赚钱方法调研（2026-10-13）

说明：数字只取自下面列出的来源，没有来源的地方标“未见数据”。

一、市场与政策背景
  • 2025年全国：挂拍71.9万套（同比-6.6%），成交16.9万套（-4.4%），成交额2536.2亿（-23.6%），清仓率23.5%，平均折价率74.1%（成交价约为评估价的7.4折）；二拍成交占46.9%。住宅成交均价8082元/㎡，三四线城市4750元/㎡。一拍起拍价是评估价的0.7–1倍，二拍是0.56–0.7倍，变卖价一般等于二拍起拍价。来源：中指 https://www.cih-index.com/news/2026-01-12/54134456.html ，https://www.zhitongcaijing.com/content/detail/1391496.html
  • 最高法2024年指导意见：除法定事由外，执行法院负责腾退交付，禁止在公告里写“不负责腾退”；辅拍机构不得私下接触竞买人、不得泄露竞买人信息、本人及近亲属不得参与竞买；严打以“对接法院、清场收房”为名诱导支付高佣金的行为。来源：http://sjt.guizhou.gov.cn/zwgk/zfxxgk/fdzdgknr/yfxz/202412/t20241206_86310381.html
  • 2026-09-11 实施团体标准 T/BAA 001-2026《司法拍卖竞买辅助服务工作规程》（北京拍卖协会），规范面向竞买人的市场化代拍服务：要求有工商登记、3年内无相关处罚；要求告知“不包清场、占用/租赁/居住权、税费、无法落户、学区变动”等风险。来源：https://www.ndls.org.cn/standard/detail/2025dcaa108373810fb6ebe2adb105f7
  • 法院辅拍费示例：湖南省内不动产每拍案不超过3000元；有房产挂8万流拍仍被收费，引发争议。来源：https://www.thepaper.cn/newsDetail_forward_31387969
二、方法（按门槛从低到高排）
# 1. 法拍信息整理、自媒体、社群（门槛最低）
  • 怎么做：整理本地法拍房源、二拍和变卖清单、成交记录和小区成交价，做内容或付费社群，并给代拍、律师、贷款引流。
  • 信息差在哪：普通人不会看公告、不懂折价规律（二拍0.56–0.7倍）。中指等机构已经在卖城市月报，说明有人愿意为这类数据付费。
  • 收益：未见可靠数据。风险：内容不能夸大，不能承诺“对接法院”（最高法明确打击）。
# 2. 代拍、辅拍服务（尽调、带看、贷款、过户、腾退协调）
  • 收费：北京报价一般是成交价的1%–2%，另有咨询、代办、腾房费。有案例收了1.9%服务费加1.5%腾房费，实际作用很小。来源：https://news.bjd.com.cn/2025/04/10/11125405.shtml
  • 有机构承诺：半年交不了房就替买家付房租，一年交不了就全款回购，靠兜底赚溢价。来源：https://news.qq.com/rain/a/20250914A02M9600
  • 信息差在哪：租赁、欠费、税费、要不要补地价，这些公告里写得不全。
  • 风险：监管在收紧（团标、最高法意见），兜底合同会带来赔付责任。腾退由法院负责之后，“清场”服务的价值在下降。
# 3. 法拍房捡漏后自住、出租或转售
  • 收益：业内说法是成交价低于市场价四成（约6折）才算真捡漏；交易成本约10%，市况稳定时也有7%–8%；市场继续下跌就容易亏。来源：https://time-weekly.com/post/322670
  • 税费坑：“一切税费由买受人承担”的公告，碰上公司产权房，买方可能要承担超过成交价40%的税费（例：1000万成交，税费451万）。来源：https://news.sina.cn/2023-03-17/detail-imymczux4207343.d.html 。另有案例：成交200万、市价250万，加上欠费12万和税费60万后，总成本反而高于市价。来源：https://news.qq.com/rain/a/20250405A05W8W00
  • 其他风险：长租约（例如提前付清租金的20年租约）、占用、共有产权、多重查封；悔拍会被没收保证金。
# 4. 银行直供房、不良资产包、债权
  • 风险：一些“骨折价”的“银行直供房”实际拍的是抵押债权，可能办不了过户；大部分标的没人报名。来源：https://www.nbd.com.cn/articles/2025-11-20/4151634.html
  • 资产包的信息披露零散，估值失误可能造成致命亏损，需要律所、会所做尽调。来源：https://mp.weixin.qq.com/s/Aa_Oe1p4mb9kr-6wkhJP_g 。门槛最高，不建议新手做。
# 5. 法拍车、股权、土地、商铺
  • 本次没找到2025–2026年可靠的收益数据。商铺流动性较差：南宁2025年9月商业法拍清仓率29.66%，住宅为50.37%。
  • 平台差异（京东、阿里、公拍网、人民法院诉讼资产网）：本次没找到可靠的对比来源，未写入。
三、南宁
  • 南宁住建局（2026年6月报道）：2025年以来两级法院网拍住宅6475件，成交额约24亿，成交率62.09%，平均每套约59.7万；平均每天上架约11套。一拍流拍在增多，二拍起拍价通常是一拍的80%。来源：https://c.m.163.com/news/a/L0M08J9D0552EIPD.html
  • 2025年9月：新增上拍547套，成交351套（住宅251套）；90–120㎡、60万以下的房源成交最活跃；青秀区住宅均价7503元/㎡；住宅平均报名4.89人；二拍成交占45.58%。来源：https://www.cih-index.com/report/detail/116846.html
  • 2025年12月：成交364套，一拍占55.22%，二拍占38.74%。来源：https://www.cih-index.com/newenergy/detail/113617.html
  • 对望园路12号青年国际的启示：重点盯二拍和变卖阶段。按总成本（成交价+税费+欠费+约10%交易成本）和同小区二手成交价比较，低于6折才算有空间。具体数据还要等用户提供拍卖列表。

# 围绕非住宅的服务/信息生意
  • 法拍信息订阅/选品清单（车、罚没品、商标、车位业主专场）：门槛最低；收益未见数据。
  • 代查车况违章、代拍、鉴定、搬运拆解对接：收费标准未见数据（北京房产代拍 1%-2% 见上一节）。
