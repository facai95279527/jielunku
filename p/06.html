外盘黄金 → 国内 518880 联动自动交易系统

不是投资建议。 本项目是工程脚手架，用于验证「外盘金价短时方向 → 黄金 ETF 518880 买卖」的流程。是否有效、能否覆盖成本，必须由你自己用 paper 和小资金验证。文中未给出任何实测延迟或相关系数。

7. 风险提示（请逐条读）
  1. 延迟 ≠ 可套利。 外盘先动、518880 后跟的现象即便存在，也可能被做市商/其他程序在你之前吃掉；行情源延迟、AKShare 网页接口延迟（数秒级、不稳定）、下单链路延迟叠加后，优势可能为零或为负。
  2. 滑点与成本：ETF 买卖价差、佣金、冲击成本；频繁交易会迅速吞噬收益。
  3. 时段错配：外盘近 24 小时交易，518880 仅 A 股时段交易；隔夜/午休的外盘变动在开盘时一次性体现，系统不在非交易时段下单。
  4. T+1：518880 当日买入次日才能卖（系统按券商可用持仓判断）。
  5. IOPV 偏差：IOPV 本身由行情商估算、有更新频率，折溢价过滤只是参考。
  6. 监管与券商规则：程序化交易须遵守交易所程序化交易管理规定与券商要求（如报备、申报频率、撤单比例、异常交易监控）。QMT/MiniQMT 需在合法券商正规开户并开通权限，策略须合规；不要用高频报撤单、对倒、虚假申报等任何可能被认定为异常交易的方式。
  7. 数据源合规：AKShare 抓取公开网页数据，稳定性与使用条款以数据方为准；付费行情商的授权范围（个人/非展示用途）自行确认。
  8. 软件风险：代码可能有 bug；live 前务必读懂 signal/linkage.py、risk/guards.py，并从极小金额开始。

附：信号逻辑源码 src/signal/linkage.py（公式与信号规则）

"""外盘方向 → 518880 买卖意图。

流程（每个外盘 tick 调用 on_tick）：
1. 延迟补偿：外盘 tick 时间戳 + latency_comp_sec（若两边存在已知固定时滞，可用来对齐；默认 0）。
2. 短窗收益率：用 window_sec 内最早价格与当前价比较，单位 bp。
3. 原始方向：ret >= buy_threshold_bp → UP；<= sell_threshold_bp → DOWN；否则 FLAT。
4. 防抖动：同一方向连续 confirm_ticks 次才确认；方向中断即清零。
5. 冷却：上一个信号发出后 cooldown_sec 内不再出信号。
6. 折溢价过滤：UP 时若 518880 溢价率 > max_premium_buy_pct 不追买；
   DOWN 时若折价率 < min_discount_sell_pct（已大幅折价）不杀跌卖出。IOPV 缺失时跳过过滤并标注。
输出 Decision(action=BUY/SELL/FLAT, reason=...)。
"""
from collections import deque
from dataclasses import dataclass
from typing import Optional

BUY, SELL, FLAT = "BUY", "SELL", "FLAT"

@dataclass
class Decision:
    action: str
    reason: str
    ret_bp: float = 0.0

class LinkageSignal:
    def __init__(self, window_sec=30, buy_threshold_bp=8, sell_threshold_bp=-8, confirm_ticks=3,
                 cooldown_sec=120, latency_comp_sec=0, max_premium_buy_pct=0.3,
                 min_discount_sell_pct=-0.3, **_):
        self.window = window_sec; self.buy_th = buy_threshold_bp; self.sell_th = sell_threshold_bp
        self.confirm = max(1, int(confirm_ticks)); self.cooldown = cooldown_sec
        self.lat = latency_comp_sec; self.max_prem = max_premium_buy_pct; self.min_disc = min_discount_sell_pct
        self.hist = deque()          # (ts, price)
        self._dir = FLAT; self._count = 0
        self._last_sig_ts = None

    def _ret_bp(self, ts, price):
        self.hist.append((ts, price))
        while self.hist and ts - self.hist[0][0] > self.window:
            self.hist.popleft()
        base = self.hist[0][1]
        return (price / base - 1) * 1e4 if base else 0.0

    def on_tick(self, price: float, ts: float, premium_pct: Optional[float] = None) -> Decision:
        ts = ts + self.lat
        ret = self._ret_bp(ts, price)
        raw = "UP" if ret >= self.buy_th else "DOWN" if ret <= self.sell_th else FLAT
        if raw == FLAT:
            self._dir, self._count = FLAT, 0
            return Decision(FLAT, "无显著方向", ret)
        self._count = self._count + 1 if raw == self._dir else 1
        self._dir = raw
        if self._count < self.confirm:
            return Decision(FLAT, f"{raw} 确认中 {self._count}/{self.confirm}", ret)
        if self._last_sig_ts is not None and ts - self._last_sig_ts < self.cooldown:
            return Decision(FLAT, f"冷却中 {ts - self._last_sig_ts:.0f}/{self.cooldown}s", ret)
        action = BUY if raw == "UP" else SELL
        note = ""
        if premium_pct is None:
            note = "（IOPV缺失，未做折溢价过滤）"
        elif action == BUY and premium_pct > self.max_prem:
            return Decision(FLAT, f"溢价 {premium_pct:.2f}% > {self.max_prem}%，不追买", ret)
        elif action == SELL and premium_pct < self.min_disc:
            return Decision(FLAT, f"折价 {premium_pct:.2f}% < {self.min_disc}%，不杀跌", ret)
        self._last_sig_ts = ts; self._count = 0
        return Decision(action, f"外盘 {self.window}s 收益 {ret:.1f}bp 已确认{note}", ret)
