条件十六「竞价抢筹龙头债」实现说明（DAQMTGUANGDA_c16.py）

线上文件 DAQMTGUANGDA.py 未改动。新文件 = 原文件 + 条件十六段（插在 # ===== EMBEDDED_JSON_START ===== 之前）+ 少量挂钩。
默认 COND16_ENABLED=True、COND16_LIVE=False（SIM：不调 passorder，按行情模拟成交，只写日志/CSV）、COND16_PM_ENABLED=False。

时序
时刻 动作
9:00~9:24:30（30s 心跳） 预选池：剩余≤6亿、溢价≤50%（基本面文件）；昨日涨幅（本引擎昨日 15:01 快照 cb_rise_*.json → QMT 日K → unknown）
9:24:59.550 沪 / .700 深（50ms 主轮询） 预选池股债毫秒锚（自采；缺失时退回主缓存同刻锚）
9:25:05 官方竞价额(_official_cb_auction_yuan) 排序取前5冻结；龙头判定；保留 Top1（COND16_MAX_PICKS，最多2）
9:25:05~9:30:05 破锚：股债都破=FULL 60%；只债破=HALF_CB 30%；只股破=HALF_STK 30%；都不破=放弃
下单 限价=现价×1.01，且≤昨收×1.12；按10张取整，<10张跳过；每日1笔竞价单
买单超时 3s 未全成撤单不重挂。竞价期(9:25~9:30)挂出的单不撮合，计时从 max(下单时刻, 9:30:00) 起（下午单从 13:00:00 起）；9:30:02 全撤买单逻辑已豁免 C16
9:30~15:00 持仓管理（只在连续竞价时段判断）
14:55 尾盘清仓 EOD（COND16_EOD_CLEAR_ENABLED / COND16_EOD_CLEAR_SEC）
≥15:01 收盘涨幅快照（供次日择时门/已验证龙头）；未平仓按最新价估值写 OPEN 行；当日汇总

龙头规则：差(债开涨−股开涨)≥2pp → SPREAD；否则股债开盘都≥+5% → DOUBLE_HIGH；否则 差≥1pp 且昨日转债涨≥10% → VERIFIED。

卖出（优先级从高到低，每 200ms 判断一次）
  1. STOP_1.5：现价 ≤ 成本×(1−1.5%)
  2. ANCHOR_LOSS：现价 < 债锚 持续 30s（下午单用 13:00 重置后的锚）
  3. TIME_10M：成交满 10 分钟时检查一次；期间最高价从未到 +2% 且现价 < 成本 → 清仓
  4. TP_ALL_DD：峰值 ≥ 成本×1.04 且 现价 ≤ 峰值×(1−0.6%) → 清仓
  5. TP_HALF_DD：峰值 ≥ 成本×1.02 且 现价 ≤ 峰值×(1−0.6%) → 卖一半（仅一次；向下取10张整数）。拆不出10张（如持仓10张）→ COND16_TP1_UNSPLIT_SELL_ALL=True 全卖
  6. BE_STOP：半仓卖出成交后（COND16_BE_AFTER_HALF=True），现价 ≤ 成本 → 清剩余
  7. EOD：14:55 起清仓

两段同一回撤同时满足（峰值已≥+4%） → 直接 TP_ALL_DD 一次清仓。原固定5%止盈、旧移动止盈已删除（本条件内不存在）。
峰值从成交价起算。卖单限价=现价×0.99，3s 未成交撤单按最新价重挂同一腿。

择时门（不满足则当天不买，写 GATE/BUY_SKIP 行）
  • 昨日转债涨幅前5均值 < 5% → 关；拿不到数据 → unchecked 放行
  • 当日亏损 ≥3%（相对 g_pre925_total_asset_baseline，缺失则 g_daily_loss_baseline）→ 关；拿不到 → unchecked 放行
下午路径（测试开关 COND16_PM_ENABLED，仅条件十六）
  • 11:29:45~11:30:03 每 200ms 采样预选池（COND16_PM_UNIVERSE="PREPOOL"，可改 "POOL5"）。取 11:29:57~11:30:00 区间最后一笔（优先 tick 自带 timetag）。
  • 信号：该笔是上涨跳（价 > 前一笔成交价）且 单笔成交额增量 ≥ COND16_PM_MIN_TICK_AMT_YUAN=200万；<200万 写 PM_REJECT。按单笔额排序取 1 只（COND16_PM_MAX_TRADES）。
  • 11:29:59 价只是信号价（pm_signal_px）。13:00:00 挂买（限价=现价×1.01，仓位 COND16_PM_FRAC=30%），13:01 前没挂出去放弃。
  • COND16_PM_ANCHOR_RESET_AT_OPEN=True：13:00 后首笔有效成交（最新价>0 且成交量较午休快照增加）重置股/债锚 → pm_reset_anchor_px，pm_reset_src=first_trade_after_1300；锚下30秒用重置锚；锚重置前不判锚下。
