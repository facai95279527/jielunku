2026-10-14 Clash Verge 连接 bot 老掉线

聊天原文（按发送顺序，10-14 14:16 起）

查完了。Clash Verge 本身没坏，是几项设置叠在一起，长连接很容易断。我这个 bot 要一直挂着一条连接收发消息，所以最先出问题。

找到的原因
1. TUN 模式和系统代理同时开着。 流量要过两层，TUN 一重启或重置，走系统代理的连接也跟着断。开一种就够了。
2. 开了"自动关闭连接"。 Clash 每次换节点，都会立刻切断所有现有连接，bot 也一起掉线。
3. 订阅里有自动测速组和故障转移组。 延迟一变它们就自己换节点，加上第 2 条，bot 就会隔一阵断一次。
4. bot 的域名没有单独规则。 它们落到兜底规则，走飞鸟节点。节点不稳，bot 就不稳。
5. DNS 是 fake-ip 模式，TUN 用的是 gvisor 网络栈。 有些应用在这个组合下长连接保持得不好，也更容易断。

推荐的解决办法，按重要程度排
1. 固定用一个节点，别让它自动切换。 在飞鸟组里手动选一个稳定的节点，香港、日本或新加坡优先。
2. 在 Clash Verge 设置里关掉"自动关闭连接"。
3. 只留一种代理方式。 如果你平时只用浏览器和这个 App，留系统代理就够了，把 TUN 关掉。如果一定要用 TUN，就把网络栈改成 mixed 或 system。
4. 加一条规则，让 Cursor 和 bot 的域名固定走同一个节点。 把 cursor.com、cursor.sh、x.ai、grok.com 指向那个固定节点。
5. 更新订阅，挑丢包少的节点。 如果飞鸟节点晚高峰还是老掉，根子在机场，那就得换个更稳的套餐。
