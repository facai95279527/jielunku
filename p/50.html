家庭视频后期流水线

仅依赖 Bash、ffmpeg（含 libx264）、ffprobe 和 Python 3 标准库，不安装软件。脚本可从任意目录调用；probe.txt 和 contact.jpg 写入调用时的当前目录。输出文件会覆盖已有同名输出，但禁止覆盖输入。

家庭视频剪得保守，保留停顿、呼吸、笑声和自然环境声音，不加大量信息动效。先看内容再决定取舍，BGM 不宜盖过家人讲话。

工作流程
  1. ./probe.sh "原始素材一.mp4" "原始素材二.mp4"：查看当前目录的 probe.txt，包含时长、分辨率、fps 和所有音轨信息。
  2. 参考 plan.txt 写剪辑清单。当前附带的是合成测试素材示例，正式剪辑请替换。
  3. ./preview.sh plan.txt preview.mp4：仅渲染前五个镜头，给用户审看。不足五个则全部渲染。
  4. 用户通过样片后，执行 ./render.sh plan.txt final.mp4 渲染全片。脚本不会自动从样片进入正式渲染。
  5. 可选 ./music.sh final.mp4 "背景音乐.mp3" final_music.mp4。背景音乐循环补足，基础音量为 15%，有人声时 sidechaincompress 自动压低；音乐首尾各 1.5 秒淡入淡出。短于 3 秒时淡化各占一半，原声不做首尾淡化。只传视频与输出：./music.sh final.mp4 final_copy.mp4，则跳过 BGM，复制音视频流。
  6. ./check.sh final_music.mp4：在 10%/25%/50%/75%/95% 抽帧，拼成当前目录 contact.jpg，打印时长、首个音视频流时长差与起点差。超过 0.1 秒报警且返回状态码 2；无音轨会提示。仍需人工听看，检查内容、响度及口型同步。
plan 格式

每个有效行：源文件|开始秒|结束秒|转场(fade/cut)|备注。空行、以 # 开头的行忽略，支持带空格的路径；路径相对于 plan 所在目录，绝对路径也支持。文件名不能含 | 或换行。开始、结束为源视频时间轴上的秒数，结束不含在片段内，不能越过源文件时长。

转场字段为空默认 fade，表示本镜头到下一个镜头的转场；最后一行转场忽略。fade 默认交叉淡化 0.3 秒，画面与声音同步淡化；cut 为硬切。全片时长等于各片段时长之和减去淡化重叠。短镜头的淡化自动缩到相邻镜头较短者的一半并向下按帧取整；不足两帧的镜头请用 cut。

样片和成片均为 540×960、30 fps、H.264 Main、目标视频码率约 700 kbit/s、AAC 96 kbit/s、48 kHz 双声道，支持 faststart，像素宽高比 setsar=1。编码内容可能使实际平均码率低于目标值。横片保留完整前景，用放大模糊背景填充；竖片同样保持比例。统一帧率只补丢帧，不变速，片段长度四舍五入到最近一帧（误差最多约 0.017 秒）。

截取首个视频流和首个音轨，音视频使用同一起点与片段时长。无音轨素材补静音，音轨不足片段时长时尾部补静音。所有映射都明确指定首个流（直接读取画面使用 -map 0:v:0，复杂滤镜中使用 [0:v:0] 后映射输出标签），不携带字幕、封面之外的额外视频、数据流或其他音轨。请在 probe 后确认首个视频流就是目标画面。

中间文件使用临时目录保存无损 FFV1/PCM，结束时自动清理。长片会占用较多临时磁盘；可用 TMPDIR=/有足够空间的目录 ./render.sh plan.txt final.mp4 调整位置。渲染异常不会自动删除已有的部分输出，需重新执行。
