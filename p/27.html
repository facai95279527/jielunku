学习四步：
1. 熟悉操作（≤1h）：找视频搞清界面与对话，别拖太久。

工具原则：一款好用 Agent、使用流畅即可。举例 Codex / Claude Code / WorkBuddy / 豆包PC / 千问办公；生图视频侧 LibTV / Tapnow / Oiioii / 小云雀。

学习参考：WaytoAGI、抖音AI夜校、观猹学社。

可执行：新工具上手≤1h并出成品；Agent 只留一个用得顺的；进阶只做真实需求；变现优先商业模式与曝光。

抖音笔记总结：AI 上手与变现路径

来源：Notion「抖音」（页面几乎全是抖音视频截图，2026-10-15 编辑）

一句话

先少看多做做出东西，再用真实需求练进阶，最后靠商业模式与对外可见去变现；工具够用流畅就行，不必钻研到死。

学习四步
  1. 熟悉操作（≤1 小时）：找视频，搞清界面与对话方式；这一步不要拖太久。
  2. 跟案例练手：看视频 → 跟着做 → 做出东西。自检三问：看完了吗？实操了吗？做出成品了吗？
  3. 解决真实需求（进阶）：围绕工作提效、自己或身边人的需求；与 AI 讨论 → 动手实现。
  4. （变现见下）
工具选型原则
  • 一款好用的 Agent，使用流畅即可（不必堆很多）。
  • Agent/编程侧举例：Codex、Claude Code、WorkBuddy、豆包 PC、千问办公。
  • 生图/视频侧举例：LibTV、Tapnow、Oiioii、小云雀。
变现心态
  • ❌ 继续一味深入学 AI
  • ✅ 先搞懂别人怎么赚钱（商业模式）
  • 自问：落地了什么项目/产品？对外分享宣传了吗？找到客户了吗？
  • 关键词：被看见
学习参考

WaytoAGI、抖音 AI 夜校、观猹学社

可执行结论（给你用）
  1. 新工具上手严格卡在 1 小时内，立刻跟案例出一件成品。
  2. Agent 选一个用得顺的，别换来换去。
  3. 进阶只做「真实需求」：提效或身边人痛点。
  4. 变现优先研究商业模式与曝光，而不是再囤课。
