2. 外盘 → 国内 ETF 联动分析逻辑
2.1 驱动链条（微观结构定性，无编造统计）
COMEX GC / XAUUSD（美元计价）
        ↓  汇率 USD/CNY（或 CNH）
上金所 Au99.99（人民币/克）升贴水、库存、国内供需
        ↓  基金持仓与申赎

        ↓  二级市场供需、套利资金、情绪
ETF 成交价（518880 / 159934）

定性经验（行业常识，非本文实证）：
- A 股开盘前，外盘隔夜涨跌常被定价进集合竞价；COMEX 往往对国内开盘有领先参考作用。
- 盘中若外盘急动而 ETF 流动性不足，折溢价可短期放大，随后申赎/做市收敛（能否套利取决于门槛与成本）。
- 不要假设固定相关系数；应用你自己的历史样本估计（§2.5）。

2.2 可计算指标与公式
# （1）官方折溢价（优先用）

东财/AKShare 已给：

[
\text{折溢价率}{\text{官方}} = \frac{P{\text{ETF}} - \text{IOPV}}{\text{IOPV}} \times 100\%
]

（字段「基金折价率」符号约定以数据源为准：有的源「折价」为正，有的溢价为正——接入时打印样例核对符号。）

# （2）IOPV 定义（概念）

招募/运作中，IOPV 通常由申购赎回清单中黄金现货合约数量 × 实时价 + 现金替代/差额，再除以最小申赎单位份额得到。
精确系数以当日清单 PDF/接口为准；本文未完整核验华安 2026 年每一日清单的克数映射 → 标「需按当日清单核实」。

# （3）外盘粗算「公允参考价」（近似，非官方 IOPV）

目的：在只有 GC 与汇率时，估一个「外盘隐含的国内金价方向」，不能替代 IOPV。

假设（必须写进日志）：
- (G)：COMEX 近月或连续价，USD/盎司
- (FX)：USD/CNY（或 USDCNH）
- (31.1034768)：1 金衡盎司 ≈ 克（国际常用换算）
- (k)：升贴水与税费摩擦因子，初始可取 1.0，再用历史回归校准
- (w)：ETF 单位净值与「元/克」之间的份额换算（来自清单或 净值 / Au99.99 滚动估计）

粗算人民币金价（元/克）：

[
\hat{S}_{\text{CNY/g}} = k \cdot \frac{G \times FX}{31.1034768}
]

粗算 ETF 公允价：

[
\hat{P} = w \cdot \hat{S}_{\text{CNY/g}}
]

外盘隐含偏离：

[
\text{外盘偏离}t = \frac{P{\text{ETF},t} - \hat{P}_t}{\hat{P}_t}
]

校准 (w)：用历史日频
w_hat = NAV_t / Au99.99_t 或 w_hat = IOPV_t / S_CNY_g_t 取中位数；禁止拍脑袋写死。

# （4）隔夜外盘涨跌 → 开盘预期（监控用）

定义（示例）：

  • (G_{\text{prev,close}})：上一 A 股交易日 15:00（CST）时刻对应的 GC 价（可用当时快照）
  • (G_{\text{preopen}})：当日 09:20–09:25 前最后一笔可用 GC（注意延迟源要向前对齐）

[
r_{\text{overnight}} = \frac{G_{\text{preopen}} - G_{\text{prev,close}}}{G_{\text{prev,close}}}
]

[
r_{\text{ETF,open}} = \frac{P_{\text{open}} - P_{\text{prev,close}}}{P_{\text{prev,close}}}
]

残差（开盘跳空未解释部分）：

[
e_{\text{open}} = r_{\text{ETF,open}} - \beta \cdot r_{\text{overnight}}
]

(\beta) 必须用你自己的样本回归，本文不提供数值。

# （5）汇率贡献拆解（可选）

[
\Delta \ln(\hat{S}) \approx \Delta \ln(G) + \Delta \ln(FX)
]

可分开记录：外盘金价变动 vs 人民币汇率变动，避免把「美元跌」误当成「金价涨」。

1. 日频：ETF 开高低收、IOPV 或净值、Au99.99、USD/CNY、GC 结算或 15:00 快照

#!/usr/bin/env python3
"""gold_monitor_mvp.py — 延迟外盘 + 国内 ETF 折溢价监控骨架"""
from __future__ import annotations

import json
import time
import urllib.request
from dataclasses import dataclass
from datetime import datetime, timezone, timedelta
from typing import Any

CST = timezone(timedelta(hours=8))

@dataclass
class OverseasQuote:
    symbol: str
    price: float
    source: str
    delayed_note: str
    fetched_at: datetime

@dataclass
class EtfSnapshot:
    code: str
    price: float
    iopv: float | None
    premium_pct: float | None  # (price-iopv)/iopv*100
    fetched_at: datetime


def fetch_gc_yahoo() -> OverseasQuote:
    url = "https://query1.finance.yahoo.com/v8/finance/chart/GC=F?interval=1m&range=1d"
    req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
    with urllib.request.urlopen(req, timeout=15) as resp:
        data = json.loads(resp.read().decode())
    meta = data["chart"]["result"][0]["meta"]
    return OverseasQuote(
        symbol="GC=F",
        price=float(meta["regularMarketPrice"]),
        source="yahoo",
        delayed_note="Yahoo help: COMEX delay 30 min",
        fetched_at=datetime.now(CST),
    )


def fetch_etf_akshare(codes=("518880", "159934")) -> list[EtfSnapshot]:
    import akshare as ak  # pip install akshare

    df = ak.fund_etf_spot_em()
    out: list[EtfSnapshot] = []
    now = datetime.now(CST)
    for code in codes:
        row = df[df["代码"] == code].iloc[0]
        price = float(row["最新价"])
        iopv = float(row["IOPV实时估值"]) if row["IOPV实时估值"] == row["IOPV实时估值"] else None
        prem = None
        if iopv and iopv != 0:
            prem = (price - iopv) / iopv * 100.0
        out.append(EtfSnapshot(code, price, iopv, prem, now))
    return out


def approx_cny_per_gram(gc_usd: float, usdcny: float, k: float = 1.0) -> float:
    """粗算：美元金价 * 汇率 / 盎司克重。k=升贴水因子，需自校准。"""
    OZ_TO_G = 31.1034768
    return k * (gc_usd * usdcny) / OZ_TO_G


def should_alert_overnight(r_overn: float, x1: float) -> bool:
    """示例：|隔夜涨跌| > 参数 x1。x1 必须来自回测分位数。"""
    return abs(r_overn) >= x1


def send_telegram(token: str, chat_id: str, text: str) -> None:
    url = f"https://api.telegram.org/bot{token}/sendMessage"
    body = json.dumps({"chat_id": chat_id, "text": text}).encode()
    req = urllib.request.Request(
        url, data=body, headers={"Content-Type": "application/json"}, method="POST"
    )
    with urllib.request.urlopen(req, timeout=15) as resp:
        resp.read()


def main_loop(poll_seconds: int = 120) -> None:
    # 参数文件读取省略：x1, premium_abs_threshold 等必须外部配置
    x1 = None  # TODO: 回测后填入，例如分位数；未填则只记录不告警
    while True:
        try:
            gc = fetch_gc_yahoo()
            etfs = fetch_etf_akshare()
            line = f"[{gc.fetched_at:%H:%M:%S}] GC={gc.price} ({gc.delayed_note})"
            for e in etfs:
                line += f" | {e.code} P={e.price} IOPV={e.iopv} prem%={e.premium_pct}"
            print(line)
            # if x1 is not None and should_alert_overnight(...): send_telegram(...)
        except Exception as exc:
            print("ERR", exc)
        time.sleep(poll_seconds)


if __name__ == "__main__":
    main_loop()
