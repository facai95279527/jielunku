掼蛋练习与复盘工具

仅作线下练习和复盘。采用两副牌、四人两队的淮安/江苏竞赛口径，不实现进贡/还贡，每局从新发牌开始。规则引擎与 HTTP 服务使用 Python 标准库；模型依赖 numpy、CPU PyTorch，测试使用 pytest。不接真人对局，不识屏。

from gd.env import GuandanEnv
from gd.agents import RandomAgent, RuleAgent

env = GuandanEnv(seed=42, level=2)  # level: 2..14，14 表示 A
agent = RuleAgent()
while not env.done:
    observation, rewards, done, info = env.step(agent.act(env))
print(env.rankings, env.team_scores)

物理牌 ID 为 0..107，每副 0..51 是自然点数 2..A、花色 ♠♥♦♣，52/53 为小王/大王。gd.cards.parse_cards 支持 ♠A 红桃10 小王 等文本，按牌池取两副中的不同实体；format_cards 输出可读文本。

gd.moves.legal_moves(hand, level, last_move_on_table_or_None) 返回声明式 Move；classify(cards, level) 返回默认最佳解释，非法组合返回 None，空组合返回 PASS。beats 比较声明。Move.identities 按实际牌顺序记录替代后的 (点数, 花色)；普通组合中的配牌花色没有比较意义。同一实体牌组允许不同合法声明，例如普通顺子和同花顺；网页直接输入牌时 classify 优先解释成炸弹，再选最大点数。Move.to_dict/from_dict 可序列化声明。

环境提供 current_player、hands、legal_actions（或 legal_moves()）、remaining_counts、history、played_cards、rankings、done、team_scores。历史包含所有出牌和过牌（每项 seat/cards/move），observation(seat) 只公开该座位手牌，其余为公开信息。奖励为两队 (0/2队, 1/3队) 得分，终局前均为零。领出不允许过，step(None) 等价于过。

复盘可使用 GuandanEnv.from_state(hands=..., level=..., current_player=..., history=..., remaining_counts=..., played_cards=..., rankings=..., last_move=..., last_player=..., passed=..., done=False)。调用方用剩余物理牌随机补全未知手牌；余张数若给定，必须与补全手牌一致。支持不满 108 张的局部局面。历史可为片段，因此当前桌面、出牌者、已过牌座位须显式传入，不能仅凭历史猜测。牌不能在各家手牌与已出牌中重复。snapshot() 可直接恢复；snapshot(json_safe=True) 可经 JSON 存储后原样传入 from_state。

双上立即终局，未出完的两名对手按座位顺序附在 rankings 后；两人之间的实际先后尚未发生，此附加顺序不影响胜方或得分。RuleAgent 使用贪心组合保留策略，优先清小散牌、避免拆炸弹和单出配牌；不是全局最优手数求解器。

规则实现要点

单张、对子、三张和同点炸弹把级牌提到 A 之上、王之下；顺子则按自然点数。顺子恰好5张，A2345最低、10JQKA最高，不能绕到JQKA2；三连对恰好3对、钢板恰好2组三张，同样允许低A。三带二可带同种王对，不可三带一。红桃级牌为逢人配，只替非王，单出按级牌。炸弹序为4炸＜5炸＜同花顺＜6炸＜7炸＜8炸＜四王。所有仍在场的其他玩家都过后重开轮次；最后出牌者已出完时优先由对家接风。头游一队按队友二/三/末游得+3/+2/+1，另一队取负；双上提前结束，另外两家名次只作占位。不含进贡与还贡。

参考 DouZero 的深度蒙特卡洛（DMC）：多进程 actor 自对弈，以终局回报监督包含动作的 Q 网络。共享四座位网络，LSTM 编码近期公开历史，MLP 同时预测头游目标和归一化得分；网页胜率是 clip((wp+1)/2,0,1)，ADP 是网络得分输出乘3。与原版相比，本项目为掼蛋重新实现规则、特征与动作，没有使用原版权重；只用 CPU、约98万参数小网络，训练时间有限，不能据此声称达到论文水平或职业水平。

网页实时读取 logs/eval.csv 中最新模型对随机、规则AI的头游率与 Wilson 95% 区间，以相对点估计的最大偏差显示“±”；同时显示当前 checkpoint 的累计训练局数。评估可能来自较早权重，不能把旧评估当作新 checkpoint 的保证。无模型评估记录时显示“尚未评估”。

估计值未作概率校准，推荐可能很差。蒙特卡洛核验默认50次、最多8个候选，随机补全隐藏牌后模型四家自对弈，显示逐候选 Wilson 误差；它依赖均匀分牌假设与模型策略，并不代表真实人类对局胜率，且未校正多候选比较。CPU紧张时请用1～2局验证功能，避免大模拟。网页不包含叫牌、跨局升级、进贡、牌桌识别或线上接入。
