星星英语 · English Play

适合 6 岁儿童在横屏平板、安卓盒子和投影仪上独立玩耍的原生 Android 应用。Kotlin + Jetpack Compose，Android 8.0+，无广告、无登录、无内购，可完全离线使用。

安装试用

已构建的 APK：app/build/outputs/apk/debug/app-debug.apk。

  1. 将 APK 复制到安卓平板、盒子或安卓投影仪，用系统文件管理器打开，允许该文件管理器“安装未知应用”后安装。
  2. 启动 星星英语，应用自动横屏。优先使用盒子 HDMI 连接投影仪，或使用设备自身的屏幕镜像功能；应用本身不需要联网或投屏服务。
  3. 点击“今日冒险”，或选择泥巴农场 / 雪之歌。按大按钮听一听、找图片、翻牌配对，完成获得一颗星。
  4. 家长先在“家长 → 验证 → 测试英语声音”检查投影仪输出音量。38 段英式朗读已经打包，首次启动也能断网使用；设备有本地英式 TTS 时优先使用。

通过 USB / ADB 安装：

adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.family.englishplay/.MainActivity

包名 com.family.englishplay，显示名“星星英语”。这是开发调试签名 APK，可直接安装；升级时用 -r 保留数据。安装签名不同的版本需要先卸载，卸载会清空数据。

已实现的内容与规则
  • Home：今日 0–3 星、剩余时间、今日冒险、两世界入口、家长门。
  • 泥巴农场 4 关：一起跳泥坑 / 雨后回家 / 洗手洗澡 / 朋友来玩（每关约 7 词）。
  • 雪之歌 4 关：雪地音乐会 / 暖暖的魔法 / 一起堆雪人 / 晚安小星星（每关约 7 词）。
  • 每关：听短句 → 听词点图 → 四组声音与图片翻牌配对 → 可选跟读（前 4 词）→ 给星。
  • 英语单词与短句默认连续朗读 3 遍，遍与遍之间停顿约 2.8 秒；点「再听」会重新播 3 遍。鼓励语仍播 1 遍。
  • 世界第 1 关始终开放；完成后解锁本世界第 2 关。已完成关卡可重玩。今日冒险优先选择尚未完成的关卡。
  • 默认每天 12 分钟，家长可选 8 / 12 / 15 分钟。前台所有页面都计时，包括首页、关卡和家长页面；离开应用 / 熄屏暂停，语音也停止。到点中断学习，显示 Eyes rest! Come back tomorrow ⭐。
  • 一天最多 3 星，集齐后同样进入休息锁定。到时或满星均不能通过返回、重启、换世界继续学习；家长门仍可进入。
  • 用设备本地日期作为日界线。跨天自动清空当日时长、星星与当日领奖标记，保留关卡完成进度、分钟设置与跟读开关。应用停留在休息页跨天时也会恢复首页。
  • ViewModel + DataStore 保存设置、进度、计时与领奖标记。同一次完成返回或页面恢复不会重复给星。前台每约 250ms 写入用时，以单调时钟计算间隔，普通退出会结算当前间隔；强行杀进程可能损失最后一个不足 250ms 的计时间隔。
  • 没有摄像头 / 麦克风 / 网络权限。跟读为孩子开口、自行确认的可跳过练习，不录音、不使用在线评分。家长打开“显示可跳过的跟读环节”后出现，默认关闭。
家长门和设置

首页或休息页右上角进入“家长”，完成两位数加法，再按住按钮 2.5 秒。长按支持触屏或按住遥控器确认键。验证只在当前前台会话内有效，应用进入后台后失效。家长门用于减少孩子误触，不是安全密码系统。

设置中可以：

  • 更改每日时长。已用时长不会因切换选项而清零，调低到已用时长以下立即锁定学习。
  • 开关可跳过跟读、测试英语声音、查看当前语音来源。
  • 经页面内二次确认重置今日时长和星星；已解锁关卡保留。

离线计时使用设备日期，不对抗家长改系统时间、清除应用数据或卸载重装。建议设备日期保持正确。所有设置保存在设备上，不上传。

投影仪与遥控器

固定横屏，高对比浅底深字；页面标题 ≥32sp，主要操作按钮 ≥64dp。页面可纵向滚动，适配低分辨率盒子和系统放大字体；若底部按钮未出现，向上滑动或用遥控器继续向下移动焦点。

支持 Android TV 启动入口和横幅；主要按钮有焦点高亮，使用方向键 / 确认键操作。触控或 USB / 蓝牙鼠标是首选。Emoji 的外观由设备字体决定，不同盒子可能略有不同。

Android Studio 打开和构建
  1. 用支持 AGP 8.7 的 Android Studio 打开本目录（含 settings.gradle.kts）。
  2. Gradle JDK 选 JDK 17；SDK Manager 安装 Android SDK Platform 35、Build Tools 35.0.0（AGP 也可能自动安装 34.0.0）、Platform Tools。
  3. 本地 local.properties 填 sdk.dir=你的SDK绝对路径。此文件不进入版本控制。
  4. 等待 Gradle Sync 后运行 app，或 Build → Build APK(s)。首次获取构建依赖需联网，装好的 App 运行无需联网。

命令行：

export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$PATH"
./gradlew assembleDebug testDebugUnitTest lintDebug

当前交付环境已装 JDK 17：/home/box/jdk17，SDK：/home/box/android-sdk。可在此环境直接使用：

JAVA_HOME=/home/box/jdk17 PATH=/home/box/jdk17/bin:$PATH ./gradlew assembleDebug testDebugUnitTest lintDebug

产物：app/build/outputs/apk/debug/app-debug.apk。

自测

./gradlew testDebugUnitTest lintDebug：覆盖跨天仅重置当日数据、同日持久化规则、时间耗尽、三星硬上限、重复领奖、负时间间隔、调整时长、四关内容完整性。报告位于 app/build/reports/tests/testDebugUnitTest/index.html 和 app/build/reports/lint-results-debug.html。

安装后建议复核：

  1. 飞行模式下启动，测试朗读，完整通过 farm_1 和 snow_1，确认各自第 2 关解锁。
  2. 退出重开，确认星星、关卡、剩余时间仍在；后台停留后回来，用时不应增加该后台间隔。
  3. 第 3 颗星后点击继续，应进入休息页，重启也应锁玩。
  4. 家长验证，修改到 8 分钟、开启跟读；返回后应保留设置；重置当日后可以继续玩。
  5. 用完每日时间，确认自动进入休息页。次日再次打开，星星和时间重置，关卡进度保留。

实际构建与运行验证记录见 TEST_REPORT.md。模拟器验证不能替代目标投影仪上的音量、遥控器和远距可读性检查。
